# Procedencia de las imágenes

- `dashboard-resumen.png` y `dashboard-reportes.png` se generan desde `../demo/dashboard.html`, una réplica pública de la estructura visual del dashboard con datos sintéticos.
- `reporte-html.png` se genera desde `../demo/index.html`, producido por el renderer Python funcional con un modelo sintético.

Ninguna imagen proviene de la base de datos ni del entorno productivo.
